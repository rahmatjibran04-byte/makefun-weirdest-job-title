## Entry

**"Senior Apologizer for Self-Driving Cars"**

A job title that sounds like a real, senior corporate role — until the twist
lands: the cars drive themselves, yet someone still has to say sorry for
them. It is specific (self-driving cars, not cars in general), instantly
visual, and funny because the apology is the whole job. Seniority makes it
better: this is not an intern's gig, it is a career.

## How it works

`main.py` (Python 3.13 standard library only, no network, no model calls)
deterministically writes exactly that title to `/output/entry.txt` — no
trailing newline — then sets the file mode to `0644` and the output
directory mode to `0755` before exiting.

## Run

```sh
python3 main.py
```

For local testing, the output path can be overridden:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
